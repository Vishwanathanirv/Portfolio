About

I'm Vishwanathan R (Vishwanathan Rajagopal), a developer, and building things is my favourite hobby. I love making web products end to end, from the interface people use to the servers and networks underneath, simply because it's fun.

My foundation is in Java, and I build for the web with JavaScript, Next.js and Node.js. I'm a Red Hat Certified System Administrator with a strong interest in security: how systems get attacked, and how to build them so they hold up.

I work fluently with AI across my whole workflow, using it to research, prototype and ship faster while keeping the quality bar high.

Neemberry Store

A complete online store for a new wellness brand, built from scratch: checkout and payments, sign-in with phone verification, a live support chat and admin tools.

How it's built: built solo and running in production. A MedusaJS backend and PostgreSQL run in Docker, behind a Next.js storefront on Cloudflare.

Mock Interview AI

A voice interviewer that listens, adapts its next question and gives feedback. Tested over 50+ sessions with a 95% completion rate.

How it's built: Vapi handles the voice and speech-to-text, while Next.js and Firebase run the sessions and feedback, with a 1.2-second average AI response. Published in the ICRCET-2026 proceedings.

Next.js · Node.js · TypeScript · Firebase · Vapi
GitHub

Payment Fraud Detection

Real-time scoring that separates genuine payments from suspicious ones, with live and batch checks and drift monitoring, reaching a 93.1% F1-score and 0.985 ROC-AUC.

How it's built: an ensemble of XGBoost and CatBoost on PCA-reduced features, served through a Streamlit dashboard.

XGBoost · CatBoost · Streamlit
GitHub

Privacy-Preserving Medical Records

Hides encrypted patient records inside CT scans using reversible watermarking, with role-based access for doctors and patients.

How it's built: a Streamlit app for doctors and patients. Because the watermark is reversible, the original scan comes back exactly as it was.

Deep learning · Cryptography · Streamlit
